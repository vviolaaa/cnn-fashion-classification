# Fashion-MNIST CNN

Практична робота: проєктування архітектури згорткової нейронної мережі (CNN) для розпізнавання зображень.

## Автори
- Твоє Ім'я ([@vviolaaa](https://github.com/vviolaaa))
- Ім'я подруги ([@snizhanavovkpp2023-max](https://github.com/snizhanavovkpp2023-max))

## Опис
Класифікація зображень одягу з набору даних Fashion-MNIST (70 000 зображень 28×28, 10 класів) за допомогою CNN, реалізованої в TensorFlow/Keras.

## Що зроблено
1. Підготовка даних: поділ на train / val / test, нормалізація, приклади класів
2. Базова CNN (Conv2D → ReLU → MaxPooling2D) та аналіз `model.summary()`
3. Навчання, графіки точності й втрат, матриця помилок, метрики по класах
4. Контрольовані експерименти (кількість фільтрів, розмір ядра, спосіб зменшення розмірності, функція активації)
5. Аугментація, BatchNormalization, Dropout, рання зупинка
6. Архітектурний елемент сучасних CNN (залишковий блок ResNet / DenseNet / depthwise-згортка MobileNet)

## Структура репозиторію
- `notebooks/` — Jupyter-ноутбуки з кодом
- `src/` — допоміжні модулі
- `results/` — графіки та таблиці експериментів
- `report/` — схеми архітектур і висновок

## Запуск
```bash
python -m venv .venv
.venv\Scripts\activate        # Windows
# source .venv/bin/activate   # macOS / Linux
pip install -r requirements.txt
```
Далі відкрити ноутбук із папки `notebooks/` і виконати комірки по черзі.
