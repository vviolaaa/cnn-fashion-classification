## Пункти 2–3. Простір пошуку та параметризована модель

### Обрані гіперпараметри

Для оптимізації обрано три гіперпараметри, які безпосередньо впливають і на ємність, і на регуляризацію моделі. Базова CNN відповідає точці (filters = 32, kernel = 3, dropout = 0,0) цього простору, тому її результат є природною точкою відліку.

| Гіперпараметр | Значення | Обґрунтування меж |
|---|---|---|
| `filters` (перший згортковий блок) | 16, 32, 64 | 32 — значення базової моделі. 16 перевіряє полегшену модель, 64 — вдвічі ширшу. Більші значення для зображень 28×28 дали б швидке зростання параметрів і часу без очікуваного виграшу. |
| `kernel_size` (обидва згорткові шари) | 3×3, 5×5 | 3×3 — стандарт і база. 5×5 дає ширше рецептивне поле, що може допомогти розрізняти схожі силуети одягу, але потребує у 2,8 раза більше ваг у згортці. |
| `dropout` (після Flatten) | 0,0; 0,25; 0,5 | 0,0 — без регуляризації (як у базі); 0,5 — типова верхня межа: вище модель зазвичай недонавчається. Базова модель виявила перенавчання, тому регуляризація — логічний напрям пошуку. |

**Розмір простору пошуку:** 3 × 2 × 3 = **18 конфігурацій** (скрипт підтвердив: 18, очікувано 18).
Повний перебір усіх конфігурацій з бюджетом 15 епох коштував би 18 × 15 = 270 епох навчання, що слугує орієнтиром для оцінки економії Hyperband.

### Параметризована модель

Функція `build_model(hp)` отримує значення гіперпараметрів через об'єкт `HyperParameters` (`hp.Choice`). Значення за замовчуванням: `{filters: 16, kernel_size: 3, dropout: 0.0}`.

**Незмінні частини архітектури** (однакові для всіх конфігурацій): другий згортковий блок із 64 фільтрами, ReLU, MaxPooling2D(2×2) після кожного блоку, `padding="same"`, Flatten, Dense(64, ReLU), вихід Dense(10, softmax), оптимізатор Adam (крок навчання за замовчуванням, 0,001), функція втрат sparse categorical crossentropy.

Шар Dropout стоїть після Flatten, тому власних параметрів не додає. Кількість параметрів визначається лише `filters` і `kernel_size`:

| filters \ kernel | 3×3 | 5×5 |
|---|---|---|
| 16 | 210 858 | 227 498 |
| 32 | 220 234 (база) | 253 514 |
| 64 | 238 986 | 305 546 |

Розмір моделі змінюється помірно (від 210 858 до 305 546), бо переважну частину ваг (201 418) становлять незмінні шари Dense. Тому різниця в якості між конфігураціями зумовлена передусім якістю ознак зі згорток і регуляризацією, а не просто «розміром мережі».

Приклад для `filters = 16, kernel = 3, dropout = 0.0` (`model.summary()`): Conv2D → (28, 28, 16), 160 параметрів; MaxPool → (14, 14, 16); Conv2D → (14, 14, 64), 9 280 параметрів; MaxPool → (7, 7, 64); Flatten → 3136; Dense(64) → 200 768; Dense(10) → 650. Разом **210 858** параметрів.
