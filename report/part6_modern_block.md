# Пункт 6. Залишковий блок ResNet

Умови ті самі, що в пп. 3-5: Adam (lr = 1e-3), batch 128, seed 42, однаковий поділ даних,
EarlyStopping (val_loss, patience=4, restore_best_weights=True), до 30 епох.
Обидві моделі однакові за структурою, Dropout 0,3, без аугментації. Єдина відмінність: наявність skip-з'єднань.

## Залишковий блок
Блок обчислює y = F(x) + x, де F(x) = Conv3×3 → BN → ReLU → Conv3×3 → BN.
Після додавання застосовується ReLU. Якщо кількість каналів змінюється (32 → 64),
скіп-гілка проходить 1×1-згортку з BatchNorm для вирівнювання розмірностей.
Архітектура: Conv(32) → ResBlock(32) → MaxPool → ResBlock(64) → MaxPool → Flatten →
Dropout → Dense(64) → Dropout → Dense(10).

## Вплив на структуру
Skip-з'єднання додає лише шар Add і 1×1-проєкцію в другому блоці: +2 304 параметри (+0,8 %).
Градієнт має прямий шлях через додавання, що полегшує навчання глибоких мереж. Наша мережа
неглибока (5 згорткових шарів), тому проблема зникання градієнта тут не виникає.

## Вплив на результат
resnet_skip мав кращу test acc (93,25 проти 92,70 %), нижчий min val loss (0,1675 проти 0,1760)
і кращий F1 для найскладнішого класу Shirt (0,792 проти 0,779). Best val acc майже однакова.
Різниця в test acc (0,55 п. п.) близька до похибки вимірювання (±0,3 п. п.), модель
навчалась один раз, тому перевагу skip-з'єднання слід вважати лише ймовірною.
Час на епоху зріс на 7 %, загальний час - на 25 %, переважно через більше епох до ранньої зупинки.
